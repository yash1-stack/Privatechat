Private Browser Chat

A small, experimental, browser-only encrypted chat. Both people need this page open and the same room code.

1. Connection

Supabase is preconfigured for this website. You do not need to enter the URL or key on each phone.

Ready to connect when you join a room.

2. Create or join a room

Create a room and share its long room code privately with the other person. Anyone with the code can read and send messages in that room.

Not connected to a room.

3. Messages

Messages will appear here while the room is connected. This prototype does not keep chat history on a server.

Privacy and security limits

Messages are encrypted in the browser with AES-GCM before being broadcast, but this is an educational prototype—not an audited secure messenger. The hosting provider serves the code, and a compromised or changed page could expose messages or keys. Supabase receives encrypted message payloads and connection metadata. There is no identity verification or forward secrecy. Do not use this for highly sensitive conversations. Keep the room code private and use only the public/publishable Supabase key in this page—never a service-role secret.
